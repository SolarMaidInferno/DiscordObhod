> [!WARNING]
>
> ### Реакция антивируса
> Антивирус может среагировать на WinDivert.  
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации сетевого трафика.
> Его применяют как легальные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов считает файлы WinDivert потенциально опасными или относит их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Такое обнаружение обязательно помечено именем `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky для этого есть настройка «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно настраиваете исключения, рекомендуется добавить исключение; если нет — отключить обнаружение PUA.

## ⚙️ Использование

1. Настройте Безопасный DNS (Secure DNS)
    * В Chrome откройте «Использовать безопасный DNS» и укажите поставщика DNS, отличный от «Поставщик по умолчанию».
    * В Firefox включите «DNS через HTTPS», выберите режим «Персональный», затем пункт «Выбрать провайдера/поставщика» и вручную укажите URL. Например: `https://dns.google/dns-query`. Поставщик Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно настроить непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется пользователям Windows 11.
    * На роутерах Keenetic включите параметр «Транзит запросов». Если он отключён, настройка и работа Secure DNS на компьютере могут быть нарушены.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/SolarMaidInferno/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте «Разблокировать». Пользователям 7-Zip или PeaZip этот шаг не нужен.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный файл
    * Чтобы подобрать рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы настроить автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную

  Ручной запуск помогает проверить стратегии. Результат зависит от множества условий, поэтому **проверяйте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий**.

- [**`service.bat`**](./service.bat) — настройка автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск (`services.msc`)</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб
  - **`Check Status`** — показывает состояние обхода и служб, включая автозапущенные стратегии и WinDivert
  - **`Game Filter`** — включает или отключает обход для игр и других служб, использующих UDP и TCP на портах выше 1023.  
  После изменения параметра стратегию нужно перезапустить.  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — меняет режим фильтрации ресурсов из `ipset-all.txt`.  
  Пригодится для проверки ресурса, который доступен без zapret, но не работает с ним.  
  В скобках показан выбранный режим:
    - `none` — ни один IP не проверяется
    - `loaded` — IP сверяются со списком
    - `any` — под фильтр попадают все IP  
  - **`Auto-Update Check`** — включает или выключает автоматическую проверку обновлений
  - **`Replace active fakes`** — заменяет текущий используемый фейк другим из каталога `bin`
  - **`Update IPSet List`** — загружает актуальный список `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — проверяет наличие обновлений
  - **`Run Diagnostics`** — ищет распространённые причины сбоев zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`. Это может помочь, если приложение внезапно перестало работать.
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — проверяет сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️ Частые вопросы и неполадки

### Запускаю `general*`, но ничего не происходит

- При запуске стратегии отдельным BAT-файлом, а не через service, должен открыться процесс обхода `winws.exe`; его можно увидеть на панели задач.  
Если процесса нет, ознакомьтесь с [#522](https://github.com/SolarMaidInferno/zapret-discord-youtube/issues/522).

### Не подошла ни одна стратегия
- Откройте командную строку с правами администратора.
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается веб-версия Telegram
В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте содержимое открывшегося блокнота целиком.
  - Откройте файл `hosts` из появившейся папки в текстовом редакторе, запущенном от имени администратора.
  - Вставьте скопированный текст в конец `hosts` или замените им ранее добавленное содержимое.
  - Сохраните файл и проверьте подключение. Если проблема осталась, убедитесь, что изменения действительно записались.

#### Результат не гарантирован. Если этот способ не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/SolarMaidInferno/tg-ws-proxy) или публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Обнаружение стратегии может привести к тому, что работавший ранее вариант больше не будет помогать.
> В репозитории собрано несколько стратегий обхода. Если ни одна не подходит, создайте собственную на основе одной из них и измените её параметры.
> О параметрах стратегий можно прочитать [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок.

- Удостоверьтесь, что адрес ресурса внесён в список доменов или IP.

- Переключитесь на другую стратегию, например **`ALT`** или **`FAKE`**.

- При необходимости полностью переустановите программу (см. инструкцию ниже).

- Дополнительная информация: [#765](https://github.com/SolarMaidInferno/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить программу?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- В `service.bat` выберите `Remove Services`.
- Затем запустите `Run Diagnostics`; устраните найденные ошибки и в конце выберите Y.
- Удалите каталог zapret.
- Загрузите актуальную версию (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/SolarMaidInferno/zapret-discord-youtube/releases).
- Щёлкните архив правой кнопкой мыши и откройте свойства. Если внизу есть параметр «Разблокировать», отметьте его, нажмите «Применить», затем «ОК».
- Распакуйте архив в новый каталог в корне диска. В пути не должно быть пробелов или специальных символов.
- Поочерёдно запустите разные скрипты `general`. Проверяйте доступ к ресурсам: если они не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` и выберите стратегию.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть ресурсы, которые вы не планировали ограничивать.

### Античит сообщает о WinDivert

- Следуйте инструкции: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится в службах

1. В командной строке Windows (Win+R, `cmd`) выполните команду, чтобы узнать имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив найденное имя вместо `название_из_первого_шага`:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежний вариант перестал работать, проверьте остальные стратегии.
- См. также [#251](https://github.com/SolarMaidInferno/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, с которой открывается YouTube, и запустите её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Проверьте, помогла ли очистка кэша в приложении Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если Discord не открывается и в браузере, проверьте остальные стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/SolarMaidInferno/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь программой [tg-ws-proxy](https://github.com/SolarMaidInferno/tg-ws-proxy).
- Также можно подключиться к бесплатным MTProto-прокси из интернета.

### Не запускаются игры

Игры отличаются друг от друга, поэтому проверить и исправить работу каждой из них невозможно.

Для начала попробуйте универсальный вариант:
- Обновите ipset через `service.bat` и включите `Game Filter`.
- Если это не помогло, дополнительно включите режим `ipset any`.

Учтите: с `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Вместо этого выясните IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если решить проблему не удалось, создайте тему в разделе [Discussions](https://github.com/SolarMaidInferno/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

## 🗒️ Добавление адресов других ресурсов

Дополнить перечень адресов для обхода можно в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но фильтровать отдельный домен из этой сети не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, исключённые из фильтрации
  - Файлы с шаблоном имени **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
